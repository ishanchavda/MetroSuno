# MetroSuno

Offline-first web app for GDG Metro Hackathon problem **PS-07: Every Complaint Heard**.

## Repository structure

- `metrosuno/` - runnable web application, SQLite backend, frontend, and app documentation
- `requirement/` - PS-07-only requirement and acceptance notes

## Run

```bash
cd metrosuno
python3 server.py
```

Open `http://127.0.0.1:8000/`.

See [metrosuno/README.md](metrosuno/README.md) for credentials, workflows, and troubleshooting. See [requirement/README.md](requirement/README.md) for the scoped hackathon requirement.
